# Backend

API prevista: FastAPI + SQLModel + SQLite.

Responsabilidades:
- autenticación y perfiles;
- catálogo y metadatos persistentes;
- gestión de solicitudes y estados;
- endpoints para la interfaz web.

La implementación de modelos, migraciones, validaciones y pruebas se incorporará en la fase 1. La API no debe almacenar datos persistentes dentro de la caché multimedia.
